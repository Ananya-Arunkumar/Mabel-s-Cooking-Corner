# Mabel-s-Cooking-Corner
A sweet cooking website inspired by the early 2000's website aesthetic. Something feels off though...

Thank you so much for checking out my little game! As the little tagline mentioned, this is supposed to be a recipe website which takes a spooky turn. It'll take about 20 minutes to complete the entire game (is it a game or more of a puzzle website?) if you read all the material. 

In order to access the game, simply click on the link in the About section, which should take you to the website. Here it is linked below if you can't find it: 

https://ananya-arunkumar.github.io/Mabel-s-Cooking-Corner/ 

Below, I've attached a small gameplay guide in case you get stuck or just want to explore the important parts:

1. When you first enter the website, I'd recommend starting with the main links (Start Here, Recipe Pages). I'd recommend reading the start me just to get background information on Mabel. For the recipes, the most important things to read are the introductions and Mabel's note at the end. The recipes should all be accurate so you can follow them if you want to but don't make me if it doesn't turn out good.

2. Once you've explored those, head over to the footer on the recipe/start page(s). Hover over the links, click them. Once you've done that, go over to doing the same on the main page. When you're clicking links on the main page's footer, I'd recommend clicking the links in the order that they're in.

**MAJOR SPOILERS AHEAD: PROCEED WITH CAUTION**

3. When you click on the contact me page, it should lead to a Missing Poster page. Read through it. Make connections. Form theories. Once you're done with that, click the button and the website should guide you to where you need to be/

4. Once you've reached the corrupted main page, notice the key differences. Try to figure out what's different from the normal page. Explore the footer links a bit. Explore the footer in general (can you tell I'm really proud of my footers?). No, the footer links on the corrupted main page will never lead to anything, they will only display alerts.

5. Read through the final recipe. If there is one recipe that you need to read all the way through, it's this one.

Congratulations, you've reached the end of Mabel's cooking corner!!
